# OSI Model Notes

The OSI (Open Systems Interconnection) Model explains how data is communicated between devices over a network.

## The 7 OSI Layers

### Layer 7 — Application
Provides network services directly to applications used by the user, such as web browsers and email applications.

### Layer 6 — Presentation
Handles data formatting, translation, encryption, and compression.

### Layer 5 — Session
Establishes, manages, and terminates communication sessions between devices.

### Layer 4 — Transport
Provides end-to-end communication. TCP provides reliable delivery, while UDP provides faster but less reliable delivery.

### Layer 3 — Network
Handles logical addressing and routing using IP addresses.

### Layer 2 — Data Link
Handles communication on the local network and uses MAC addresses.

### Layer 1 — Physical
Transmits raw bits through physical media such as cables, fiber, or wireless signals.

- IP addresses → Layer 3 (Network)
- MAC addresses → Layer 2 (Data Link)
- TCP/UDP → Layer 4 (Transport)
