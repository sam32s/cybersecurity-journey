# Metasploitable 2 Security Assessment Lab

## Project Overview

This project documents a hands-on security assessment of Metasploitable 2 using Kali Linux in an isolated VirtualBox lab.

## Lab Environment

- Attacker Machine: Kali Linux
- Target Machine: Metasploitable 2
- Virtualization: Oracle VirtualBox
- Network: Isolated Internal Network
- Tools: Nmap, SSH, Wireshark

## Objectives

- Identify active network services.
- Perform port scanning and service enumeration.
- Examine potential security weaknesses.
- Understand Linux users and permissions.
- Document findings and security recommendations.
